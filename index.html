MICCAI 2026 Tutorial

ImFusion SDK Tutorial
for accelerated medical
imaging research

Learn how to move faster from data and annotation to AI workflows, visualization, and real-time interaction in one research-ready software environment.

This half-day tutorial gives researchers a practical introduction to unified workflows for image analysis, intervention support, and translational prototyping. Start with research, experiment quickly, and see your ideas come to life on a product-grade SDK that keeps the path to the clinic short.

Half-day tutorial Python, C++, Web Live Demos AI Coding

Highlights

  • Combine loading, visualization, annotation, and processing in one medical imaging workflow.
  • Prototype faster in Python and connect data pipelines to models more efficiently.
  • Extend workflows for real-time interaction, streaming, and other performance-critical tasks.
  • Suitable for both new ImFusion users and researchers already building more advanced workflows.
  • Attendees receive free academic license keys for Suite, Labels, and SDK.
  • Example projects and demo data will be available on GitHub so you can continue exploring the workflows after the session.

Schedule

From fundamentals to research use cases

8:30 - 9:15

Welcome and ImFusion SDK Fundamentals

Dr. Wolfgang Wein, Dr. Raphael Prevost

We will give a quick company overview and highlight lessons learned over decades of R&D and product translation on medical devices. We will then introduce the ImFusion ecosystem and summarize the main architectural decisions underlying our SDK, including a comparison with 3D Slicer and other relevant frameworks. We will continue with the fundamentals of the annotation features, common processing workflows, and key APIs across C++, Python and Web.

9:15 - 10:00

Rapid Prototyping in Python

Ilja Manakov

In this session, we will demonstrate how the ImFusion Python API enables rapid development and experimentation. The session will cover working with medical images and volumes, visualization and processing workflows, and combining existing SDK functionality with custom Python code to quickly prototype new ideas.

10:00 - 10:30

Break

10:30 - 11:00

From Datasets to AI Models

Ilja Manakov

Building on the first Python session, we will demonstrate how Python and the ImFusion SDK can be used throughout data-driven and machine-learning workflows. The session will cover managing and preparing imaging datasets, connecting training and inference pipelines, and bringing model outputs such as segmentations and predictions back into ImFusion for visualization and further processing.

11:00 - 11:45

Real-Time Prototyping with C++

Dr. Maria Tirindelli

Moving from rapid experimentation to high-performance applications, this session will demonstrate how to develop custom functionality using the ImFusion C++ API. It will cover the SDK’s core concepts for implementing algorithms and processing pipelines, working with real-time data streams, and integrating custom components into ImFusion applications. Practical examples will illustrate how C++ can be used to build responsive, performance-critical workflows for real-time medical imaging.

11:45 - 12:30

The Future of Medical Imaging Prototyping: Web Apps and AI-Assisted Development

Dr. Raphael Prevost

How can researchers turn their code into interactive applications that are easy to build, share, and demonstrate? In this session, we will introduce the ImFusion Web SDK, the new JavaScript counterpart of our framework, bringing familiar ImFusion concepts to interactive medical imaging applications in the browser. We will demonstrate how it can be used not only to build compelling research demos, but also to create tools that improve everyday research workflows. We will also discuss how AI-assisted coding is changing research software development, share how we use it at ImFusion, and show how it can help researchers develop with the ImFusion SDK more effectively. The session concludes with an open discussion and Q&A.
